# facetful-grid

A small, framework-free, read-only data grid for
[facetful](https://github.com/kindly/facetful) results. It aims to paint
quickly on page load and scroll smoothly through millions of rows, in about
15 KB gzipped with no runtime dependencies.

Nothing is built yet. Start with [docs/design.md](docs/design.md), which
records the decisions, the measurements behind them and what earlier grids
taught us.
